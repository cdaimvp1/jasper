What this doesn't claim

Stated plainly, not as a disclaimer — this is what makes the two sections above credible rather than a sales pitch.
1

There's still an irreducible human-review floor

High-stakes items — anything past a Hard Stop, anything with real dollar value — still need Marc's own judgment. Jasper reduces the time to a decision point, not the need for the decision itself. Read the estimates above as "time to first draft / first read," not "time to close."

2

Saved time may become more assigned volume, not free time

If Jasper's real effect is that Marc can handle more items per week at the same quality bar, that's a genuine productivity story — just a different one than "this gives Marc N hours back." Both readings can be true at once; this page doesn't assert one over the other.

Gate Board
Every prerequisite rule at a glance, with how many currently-open issues each one is actually gating right now — computed live each time you load this, not a separate counter that could drift. A rule gating zero issues isn't wrong, just dormant right now.

Prerequisite rules (Aristotle)
Teach Jasper a gate: "don't treat X as ready to act on until Y has been seen for the same project or supplier." For example, a signature request shouldn't be flagged ready to sign until an approved purchase order has come through for that same deal. Jasper only ever says "no confirmation seen yet" — never that something hasn't happened — since it can only see what's actually arrived in your mail.
